# 拍拍猫 · AutoPat

微信「拍一拍」自动回拍 Xposed 模块。对方拍你一下，模块自动帮你拍回去。

- 当前版本：**0.1010**
- 适用：微信 8.0.79 / Android 8.0+（minSdk 24）
- 环境：LSPosed / 君子 Xposed 等任意 Xposed 框架，需 root

---

## 功能

| 功能 | 说明 |
|---|---|
| 自动回拍 | 对方拍你一下，立即回拍，不弹窗、不模拟点击，全后台静默 |
| 延迟可调 | 0 ~ 5 秒，0 表示立刻回拍 |
| 不拍名单 | 填 wxid，一行一个；名单里的人拍你，不回拍 |
| 群聊开关 | 可单独关闭群聊里的自动回拍 |
| 夜间静默 | 可选，夜间不回拍 |
| 每日上限 | 0 表示不限 |

## 安装

1. 安装 `AutoPat_0.1010.apk`
2. 打开模块管理器（LSPosed / 君子 Xposed）→ **模块** → 勾选 **拍拍猫**
3. 进入 **作用域**，勾选 **微信**（com.tencent.mm）
4. 强制停止微信后重新打开

---

## 打开设置页

有两种方式，任选其一：

- **桌面图标**：桌面上的「拍拍猫」图标，点进去就是设置页
- **模块管理器**：LSPosed / 君子 Xposed → 模块 → 拍拍猫 → **模块设置**

> 桌面图标只有一个，不会重复。

---

## 不拍名单怎么填

设置页 →「不拍名单」→ 输入框里填 wxid，**一行一个** → 点「保存名单」。

**怎么查 wxid：**
微信 → 打开对方聊天 → 点右上角头像 → 看「微信号」那一栏（不是昵称）。

填好后**不需要重启微信**，下一次拍一拍就生效。

---

## 想从微信视野里彻底隐身

如果想让微信检测不到本模块，用 **Hide My Applist（隐藏应用列表）**：

1. 打开 Hide My Applist
2. 创建模板 / 直接编辑微信的规则
3. 把 `com.greenbubble.tapcat` 加入黑名单
4. 应用到微信

---

## 常见问题

**Q：拍了没反应？**
检查三处：① 模块管理器里拍拍猫是勾选状态 ② 作用域勾了微信 ③ 改完设置后重启过微信。

**Q：设置页改了不生效？**
设置页底部提示「改完设置后无需重启微信」，正常情况下即时生效；若没生效，强制停止微信再打开即可。

**Q：桌面图标重复？**
0.1010 已修复，只保留一个入口。
